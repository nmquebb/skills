# shopkit

Plain ES modules in `src/`, one module per concern, each with a `node:test` file in `test/`. Run
`npm test` before handing work back. Amounts of money are integer cents.

This repository uses the q skill suite. Its lifecycle (`q-spec` → `q-plan` → `q-reconcile` →
`q-implement` → `q-reconcile` → `q-archive`) is opt-in; configuration lives in
`.agents/q/config.yaml`; project addenda in `.agents/q/`.
